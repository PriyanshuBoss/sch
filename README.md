# National Scholarship Portal

National Scholarship Portal is a web-based application designed to simplify and digitize the scholarship process for students. It serves as a one-stop solution through which various services including student registration, scholarship application, application processing, sanction, and scholarship disbursal are managed efficiently.

---

# 🚀 Features

## Student Features

* Student registration
* Secure login system
* Online scholarship application
* Update student details
* Password recovery
* Application status tracking
* Print application/login details

## Admin Features

* Admin dashboard
* Manage scholarship applications
* Verify student details
* Approve or reject applications
* Monitor scholarship disbursal process

# 📂 Project Structure

| File/Folder               | Description                          |
| ------------------------- | ------------------------------------ |
| `WEB-INF`                 | Configuration and deployment files   |
| `pics`                    | Stores images and static assets      |
| `home.jsp`                | Homepage of the portal               |
| `registration.jsp`        | Student registration page            |
| `registrationSuccess.jsp` | Registration success page            |
| `registrationFailure.jsp` | Registration failure page            |
| `login.jsp`               | Student login page                   |
| `loginDetails.jsp`        | Displays login details               |
| `loginMediate.jsp`        | Login processing page                |
| `forgotPassword.jsp`      | Password recovery page               |
| `details.jsp`             | Displays student/application details |

| `updateDetails.jsp`       | Update details processing            |
| `updatePassword.jsp`      | Password update page                 |
| `adminControl.jsp`        | Admin management dashboard           |
| `printLogin.jsp`          | Printable login details              |
| `successApplication.html` | Successful application page          |
| `aboutUs.html`            | About portal information             |
| `helpline.html`           | Help and support page                |
| `logout.html`             | Logout page                          |

# 📦 Setup Instructions

## Prerequisites

* Java JDK
* Apache Tomcat Server
* Oracle Database
* IDE (Eclipse / IntelliJ IDEA / NetBeans)

---

# ⚙️ Installation

## Clone Repository

```bash id="8h1s3q"
git clone <repository-url>
```

## Import Project

1. Open IDE
2. Import as Dynamic Web Project
3. Configure Apache Tomcat Server

---

# 🗄️ Database Configuration

1. Create Oracle database schema
2. Configure database connection inside project files
3. Import required tables

---

# ▶️ Run Project

1. Start Apache Tomcat Server
2. Deploy the project
3. Open browser:

```text id="wp9k3g"
http://localhost:8080/ScholarshipPortal
```
